# Instruções do projeto

Leia `AGENTS.md` e `README.md` antes de alterar o sistema. Este repositório é uma distribuição pública: nenhum dado pessoal, sessão, credencial, banco ou mídia real pode ser adicionado ao Git.

Ao inspecionar uma instalação remota, o checkout local não é a instância em execução. Use
`node tools/instancia.mjs <nome>` e nunca conclua estado de produção olhando apenas a cópia local.
