# Segurança

Não abra uma issue pública com credenciais, sessões, conversas, fotos, telefones ou outros dados pessoais.

Ao encontrar uma falha, use o canal privado de aviso de segurança do GitHub deste repositório. Inclua impacto, versão afetada e uma reprodução sem dados reais.

Revogue imediatamente qualquer token ou sessão que tenha sido exposto; apagar o arquivo em um commit posterior não remove o segredo do histórico.
