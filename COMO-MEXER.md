# COMO MEXER — Demonstração Vendas Multicanal

## Abrir

No Terminal:

```bash
cd ~/projetos/tim/vendas-multicanal-demo
npm run demo
```

Depois abra: http://127.0.0.1:8099

Senha: `demo2026`

O terminal precisa continuar aberto. Para encerrar, pressione `Control+C` nele.

## Restaurar antes de uma nova gravação

```bash
cd ~/projetos/tim/vendas-multicanal-demo
npm run demo:reset
```

Esse comando recria somente o banco da demonstração. Ele não mexe no sistema principal (`~/projetos/tim/vendas-multicanal`).

## O que mostrar

1. Tinder: cards, duas pendências, vínculos e rascunho/envio.
2. WhatsApp: cinco conversas, etiquetas, modos, fotos, áudios e entrega.
3. Instagram, Badoo, Telegram e Meu Patrocínio: abrir uma conversa e simular envio.
4. Agenda: três compromissos e uma proposta aguardando aprovação.
5. Projetos: tarefas, próximos passos, notas, lembretes e hábitos.
6. Config → Grana: necessidades, quatro serviços e PIX fictício.
7. Config → Fotos e áudios: quatro imagens sintéticas e dois áudios sintéticos.
8. Progresso, Pessoas, Monitor, Diário e Assistente.

O selo amarelo `DEMO LOCAL · DADOS FICTÍCIOS` prova que a tela é uma simulação. Nenhuma ação sai do computador.
