# Projetos e agenda no prompt

O sistema separa projetos pessoais de compromissos com data/hora.

- Projeto é contexto persistente: objetivo, estado, próximos passos e lembretes.
- Compromisso ocupa a agenda local e pode ser espelhado no Google Agenda.
- Conversas externas recebem somente o contexto necessário e autorizado.
- Dados de uma pessoa nunca entram no prompt de outra.
- Caminhos, ids de calendário e credenciais são configuração privada, não código.

Quando não houver projeto ou agenda configurados, os blocos correspondentes devem ficar fora do prompt sem alterar o restante.
