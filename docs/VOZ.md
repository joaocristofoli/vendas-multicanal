# Como medir a voz

Guarde aqui apenas o método e, na instalação privada, mantenha os resultados fora do Git.

Ferramentas disponíveis:

```bash
node tools/analisar-voz.mjs
node tools/amostras-voz.mjs
node tools/voz-intima.mjs
node tools/padrao-troca.mjs
```

Meça tamanho, bolhas, pontuação, acentos, abreviações, risada, perguntas e ritmo. Use somente mensagens autorizadas. Não copie nomes, telefones, textos integrais ou estatísticas identificáveis para a distribuição pública.
